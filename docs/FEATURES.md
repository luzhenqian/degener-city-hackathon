# 功能特性文档

## 已实现功能

### 1. 钱包连接

支持主流 Solana 钱包：
- Phantom
- Solflare
- 其他兼容 Wallet Adapter 的钱包

功能包括：
- 一键连接/断开
- 自动重连
- 账户切换检测
- 余额实时显示

### 2. 3D 场景

交互式 3D 环境：
- 流畅的相机控制
- 优化的渲染性能
- 动态光照效果
- 后处理特效

### 3. 多语言支持

- 自动检测浏览器语言
- 手动切换语言
- 支持的语言：
  - 简体中文
  - English

### 4. 响应式设计

- 适配桌面端
- 移动端优化（开发中）
- 触摸手势支持（开发中）
